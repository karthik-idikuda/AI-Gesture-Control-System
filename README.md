# AI Gesture Control System

Touch-free device control system using hand gesture recognition for cursor movement, clicks, scrolling, and media playback.

## Features

- Real-time hand tracking with 21-point landmark detection
- Gesture-to-action mapping for cursor, click, scroll, and media controls
- Low-latency inference for smooth interaction
- Configurable gesture library
- Multi-hand support
- System tray integration for background operation

## Tech Stack

Python, OpenCV, MediaPipe, PyAutoGUI, NumPy

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/karthik-idikuda/AI-Gesture-Control-System.git
cd AI-Gesture-Control-System
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```
